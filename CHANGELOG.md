# Changelog

All notable changes to this project should be documented here.

The project follows semantic versioning:

- `v0.x` for early, unstable work
- `v1.0.0` for the first stable public release
- `v2.0.0` and later for backward-incompatible API or behavior changes

## v1.0.0 - 2026-07-16

- Public task model with enriched and local declarations
- Runtime facade for lifecycle control and runtime status
- Offloader controller with scheduler-aware built-in policies
- Port and task regression harnesses backed by ESP32 hardware
- Public API cleanup with compatibility wrappers and explicit ownership guidance
- EDF creation support remains deferred for v1
