# Code of Conduct

We want this project to stay welcoming, practical, and useful for contributors of all backgrounds.

## Expected behavior

- Be respectful and direct.
- Critique ideas, not people.
- Keep discussions focused on the project.
- Assume good intent, but be specific about problems.
- Help others learn by sharing context and concrete examples.

## Unacceptable behavior

- Harassment, discrimination, or personal attacks
- Deliberate disruption of review or collaboration
- Sharing private information without permission
- Any behavior that makes participation unsafe or hostile

## Enforcement

Maintainers may remove or edit content, close issues, or decline contributions that violate this code of conduct.

For serious concerns, use GitHub's private security or moderation channels where available.
